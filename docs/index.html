세계관 & 스토리

배경 설정

지상의 화학물질 탐사소가 핵폭탄 사건으로 폭발하면서 지상은 극도로 오염된다. 살아남은 인류는 지하 벙커를 건설해 생활하지만, 결국 오염된 지상을 되찾고자 한다. 플레이어는 지상 조사단 일원으로서 오염된 공장에 진입해 변이 몬스터를 정화하고 귀환하는 미션을 수행한다.

플레이어 정체
  • 지상 조사단 소속 요원
  • 화학물질 방호복 착용
  • SDS(안전보건자료) 기반 정화 무기 사용
  • 벙커에서 장비 수리·강화 후 출동
몬스터 정체
  • GHS 화학물질에 노출된 변이 동물
  • 화학물질에 오염된 연구원
  • 각 GHS 유형별 고유 외형·패턴 보유
  • 정화 성공 시 인간으로 복귀

  • 제한된 시야 속에서 오브젝트 탐색

  • 벙커에서 무기·방어구 수리·강화
  • 맵 전체가 점차 정화된 환경으로 변화

씬 구성 (UI)

🏭 공장 필드 씬 (이동 화면)
  • 도트 기반 2D 탑다운 or 사이드뷰 필드
  • 맵 이동 UI (미니맵 또는 구역 표시)
  • 시야 제한 UI — 화면 외곽 어둠 처리
  • 불 아이템 사용 시 시야 반경 확장
  • 몬스터 조우 이펙터 (접촉 또는 일정 범위)
  • 인벤토리 퀵 접근 버튼
⚔️ 전투 씬 (1:1 화면)
  • 1:1 전투 화면으로 씬 전환
  • 선택지 창 (전투 / 아이템 / 도망)
  • 플레이어 도트 스프라이트
  • 몬스터 도트 스프라이트 (GHS 유형별 고유)
  • 몬스터 오염 게이지 UI (HP 대신)
  • 정화 게이지 0 → 포획 가능 표시
  • 정화 성공 텍스트: "정상 상태로 복귀했습니다."

확정 시스템

🎒 인벤토리 시스템
  • 아이템 획득 시 인벤토리에 수동 배치
  • 화학물질, 무기, 장비 슬롯 구분
  • 타르코프 참고: 상자 오브젝트에서 장비 발견
🗺️ 듀얼 씬 전환
  • 이동 화면 ↔ 전투 화면 분리
  • 몬스터 조우 이펙터로 전투 씬 트리거
  • 포켓몬 DS 스타일 전투 전환 연출
🌿 맵 정화 변화
  • 몬스터 정화 수에 따라 맵 비주얼 변화
  • 오염 → 중간 → 정화 3단계 타일 교체
  • 플레이어에게 성취감과 시각적 피드백 제공
🔧 무기·장비 강화
  • 벙커 메인 메뉴에서 수리 및 강화
  • 타르코프 참고: 수리 비용 = 수집 화학물질
  • 강화 단계별 효과 상승 (정화 효율 +)
⚔️ 오염 게이지 전투
  • 몬스터 HP → 오염 게이지로 대체
  • 올바른 무기로 공격 시 게이지 감소
  • 틀린 무기 사용 시 플레이어 패널티
📦 포획 시스템
  • 오염 게이지 = 0 시 포획 가능 상태 활성화
  • 몬스터 헌터 참고: 갈무리 → 인벤토리 수납
  • 포획 성공 = "정상 상태로 복귀" 연출

GHS + SDS 전투 데이터셋

각 몬스터는 실제 GHS(화학물질 국제조화시스템) 위험 유형을 기반으로 설계되며, 대응 무기는 SDS(안전보건자료)의 처리 방법에서 도출됩니다.

ID GHS 유형 색상 위험 물질 위험도 위치 몬스터 타입 전투 패턴 정화 방법(SDS) 정화 효과
01 GHS05 부식성 ● 초록 염산
배관 점검실 피부가 녹아내리는 직원 산성 장판 생성 중화제 장판 제거 + 오염 감소
02 GHS05 부식성 ● 초록 황산 미스트
배터리 처리실 산성 안개에 뒤덮인 직원 시야 차단 안개 중화 + 흡착 시야 회복
03 GHS06 독성 ● 보라 염소
소독 약품 저장소 질식 상태 직원 독안개 분사 환기 + 흡착 독 제거
04 GHS06 독성 ● 보라 암모니아
냉각 설비실 호흡기 손상 직원 질식 구역 생성 희석 + 환기 안전 구역 생성
05 GHS02 인화성 ● 빨강 벤젠
원료 저장 구역 불안정 상태 직원 폭발 흔적 생성 냉각 + 차단 폭발 위험 제거
06 GHS02 인화성 ● 빨강 톨루엔
도료 혼합실 휘발성 중독 직원 빠른 돌진 환기 + 냉각 속도 감소
07 GHS07 자극성 ● 노랑 포름알데히드
사무동 보관실 피부/눈 자극 직원 시야 흐림 환기 시야 회복
08 GHS07 자극성 ● 노랑 아황산가스
가스 처리 라인 기침 반복 직원 충격파 흡수제 패턴 약화
09 GHS09 환경유해 ● 파랑 폐수 오염
폐수 처리조 액체형 변이 직원 바닥 확산 흡착 확산 차단
10 복합 위험 BOSS ● 검정 복합 누출
중앙 반응로 최종 변이체 혼합 공격 환기→중화→흡착 순차 단계별 약화
7

무기 시스템 (최소 구현)

초보 팀 기준으로 3가지 핵심 무기만으로 충분히 구현 가능. 나머지는 조합 UI로 표현.

🟢
중화제 (Neutralizer)
산·염기 오염에 효과적. 부식성(GHS05) 몬스터 특효. 장판 제거 및 오염 구역 무력화.
부식성 특효
🟣
환기 장치 (Ventilator)
가스·독성 오염에 효과적. 독성(GHS06), 자극성(GHS07) 몬스터 특효. 독안개 및 질식 구역 해제.
독성 특효
🔵
흡착제 (Adsorbent)
액체·확산 오염에 효과적. 환경유해성(GHS09) 몬스터 특효. 바닥 확산 및 액체형 공격 차단.
환경유해 특효
🚫

중요: 화학물질 무기로 적을 직접 처치하면 안 됩니다. 오염 게이지를 0으로 낮춰 정화·포획하는 것이 목표. "화학물질을 안전하게 다루자"는 핵심 메시지를 유지해야 합니다.

8

직관성 색상 가이드

플레이어가 생각 없이도 맞출 수 있는 구조. GHS 아이콘 색상 = 무기 선택 힌트.

초록 (GHS05 부식성)
염산, 황산 미스트 — 산성 장판·안개 공격
→ 🟢 중화제 사용
보라 (GHS06 독성)
염소, 암모니아 — 독안개·질식 구역 공격
→ 🟣 환기 장치 사용
빨강 (GHS02 인화성)
벤젠, 톨루엔 — 폭발·돌진 공격
→ 🔴 냉각 장치 사용
노랑 (GHS07 자극성)
포름알데히드, 아황산가스 — 시야 흐림·충격파
→ 🟡 환기 + 흡수제 사용
파랑 (GHS09 환경유해)
폐수 오염 — 바닥 확산 공격
→ 🔵 흡착제 사용
검정 (복합 위험 BOSS)
중앙 반응로 최종 변이체 — 혼합 패턴
→ 순차 정화 (환기→중화→흡착)

전투 로직 코드 스니펫

Unity C# 기준 핵심 전투 구조. 초보 팀이 바로 참고할 수 있도록 최소화된 로직.

// 오염 게이지 기반 전투 핵심 로직
public class BattleManager : MonoBehaviour
{
    public float contaminationGauge = 100f; // HP 대신 오염 게이지
    public float playerHP       = 100f;
    public float purifyDamage   = 20f;
    public float wrongPenalty   = 10f; // 틀린 무기 사용 시 플레이어 피해

    public void UseWeapon(WeaponType weaponType, MonsterData monster)
    {
        if (weaponType == monster.weakWeaponType)
        {
            // 올바른 무기 → 오염 게이지 감소
            contaminationGauge -= purifyDamage;
            Debug.Log("정화 진행 중...");
        }
        else
        {
            // 틀린 무기 → 플레이어에게 페널티
            playerHP -= wrongPenalty;
            Debug.Log("잘못된 처리 방법입니다!");
        }

        CheckPurification();
    }

    private void CheckPurification()
    {
        if (contaminationGauge <= 0f)
        {
            // 오염 게이지 0 → 포획 가능
            Debug.Log("정상 상태로 복귀했습니다.");
            EnableCapture();
        }
    }
}
// 몬스터 데이터 구조
public enum WeaponType
{
    Neutralizer,  // 중화제  — GHS05 부식성 특효
    Ventilator,   // 환기    — GHS06/07 독성·자극성 특효
    Adsorbent     // 흡착제  — GHS09 환경유해 특효
}

[System.Serializable]
public class MonsterData
{
    public string     monsterName;
    public WeaponType weakWeaponType; // Inspector에서 지정
    public float      maxContamination;
    public Sprite     monsterSprite;   // GHS 유형별 고유 도트 이미지
}

주의사항 & 개발 제약

⚠️

화학물질 무기로 적을 직접 처치 금지
화학물질을 안전하게 다루자는 게임의 핵심 메시지가 사라집니다. 오직 오염 게이지를 낮춰 정화·포획하는 방식으로만 진행.

👥

초보자 3~4명, 13일 개발 분량으로 설계
과도한 시스템 추가 금지. 무기 3종, 씬 2개, 몬스터 10종 이내의 최소 구현 원칙을 유지. 추가 기능은 기본 루프 완성 후 검토.

🎨

몬스터 이미지 중복 금지
각 몬스터는 GHS 유형별 고유 외형을 가져야 합니다. 같은 도트 스프라이트 재사용 시 몬스터 개성이 사라져 전투 직관성이 저하됩니다.
